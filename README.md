# 🧪 The Math Goblin's Laboratory

> "Surely this folder structure makes sense."
> — Me, five commits ago.

Welcome to my digital junk drawer.

This repository is a collection of tiny projects, experiments, half-finished ideas, accidental discoveries, and the occasional piece of code that somehow works on the first try (rare).

## 🤔 What's in here?

Every folder is basically its own little adventure.

Some are:

* 📈 Statistics experiments
* 🔢 Math explorations
* 🐍 Python practice
* 🤖 Machine Learning attempts
* 📊 Data Science notebooks
* 🧠 "Wait... why does this formula work?" moments
* 🔥 Code I wrote at 2 AM and am now too afraid to delete

Think of this repo as a giant notebook where every page decided to become its own project.

## 🎯 Goal

I'm using this repository to learn:

* Mathematics
* Statistics
* Python
* Data Analysis
* Machine Learning
* Whatever rabbit hole I fall into next

The objective isn't perfection.

The objective is to understand *why* things work instead of just importing another library and pretending I know what it's doing.

## ⚠️ Expect Chaos

Inside you'll find:

* Random notebooks
* Scripts with questionable names
* Too many comments
* Not enough comments
* Experiments that failed spectacularly
* Experiments that accidentally succeeded

## 📂 Repository Philosophy

Every folder lives its own life.

Some are complete.

Some are abandoned.

Some are waiting for Future Me™ to remember what Past Me™ was trying to accomplish.

Future Me is usually just as confused.
